# xchange icons

Generated with the built-in image generation tool. PNG exports at 16, 32, 48, and 128 pixels are referenced in the extension manifest. `icon-master.png` is the original generated artwork; exports were resized using macOS `sips`.

## Initial prompt

Use case: logo-brand. Asset type: Chrome extension icon for xchange, which converts selected currency amounts into euros. Create one square master icon, a bold euro symbol integrated with two simple opposing exchange arrows. Minimal flat vector-like design, strong silhouette and thick strokes readable at 16 pixels. Centered composition, generous but compact safe margin. Use a restrained high-contrast palette suitable for a currency utility. Transparent background outside the icon. No wordmark, no letters other than the euro symbol, no mockup, no shadows, no fine detail, no multiple icon sheet. Render at 1024x1024.

## Final edit prompt

Edit this Chrome extension icon. Preserve the blue and green exchange arrows and white euro concept. Place the entire symbol on a solid dark navy rounded square tile that fills 92% of the square canvas with transparent outer corners. Clean up euro into a perfectly solid, crisp white euro symbol without distressed texture or holes. Simplify into flat solid colors, no gradients or shadows. Keep all arrows fully within tile with clear padding. Small toolbar icon readability is essential. One square icon only.
